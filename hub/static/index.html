How the audit works

  1. Personas. Twins that differ by one sentence, such as "rent a movie first".
  2. Agents play. Claude sees only typed numbers and buttons, never page text, and picks from a fixed list of actions.
  3. Evidence. Every step is hash-chained, so a later edit is detectable.
  4. Statistics. Welch CIs, Holm and TOST, all pre-registered, give each metric a verdict.
